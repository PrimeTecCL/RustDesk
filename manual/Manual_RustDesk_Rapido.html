RustDesk — Guia rapida de instalacion

Servidor interno: rustdesk.primetec.cl

1Descargar e instalar

  1. Entra a https://rustdesk.com/download y descarga la version Windows 64-bit.
  2. Ejecuta el instalador descargado y acepta el aviso de Windows (UAC) si aparece.

2Configurar el servidor

Abre RustDesk -> icono de menu (arriba a la derecha) -> Configuracion -> pestana Red -> ID/Relay Server. Ingresa estos datos y presiona Aplicar:

Campo en RustDeskValor a ingresar
ID Serverrustdesk.primetec.cl:21116
Relay Serverrustdesk.primetec.cl:21117
API Server (opcional)https://rustdesk.primetec.cl
Key4KDYvmOasvAG4dG1k+KYwBsuprgwP1DownC21Jw18Gs=
Sobre los puertos Los puertos 21116 (ID) y 21117 (Relay) son los que tiene configurados nuestro servidor.
Importante Copia la Key tal cual aparece, sin espacios al inicio ni al final.

3Listo

RustDesk asignara un nuevo ID para tu equipo. Ese es el identificador que debes compartir con soporte TI de ahora en adelante.
