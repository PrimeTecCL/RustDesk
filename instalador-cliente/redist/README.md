# redist/

Coloca aquí el instalador MSI **oficial** de RustDesk antes de compilar, con
el nombre exacto que espera el script (según la versión definida en
`RD_VERSION` al compilar, por defecto `1.5.0`):

```
rustdesk-1.5.0-x86_64.msi
```

Descárgalo desde la página oficial de releases:

https://github.com/rustdesk/rustdesk/releases

> No se versiona el binario `.msi` en este repo (ver `.gitignore`). Cada quien
> debe descargar el oficial para evitar distribuir binarios de terceros dentro
> del repositorio de código.
